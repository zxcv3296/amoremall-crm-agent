# LLM 토큰 구성 상세 분석

## 1. 전체 구조 개요

```
┌─────────────────────────────────────────────────────────────┐
│                    LLM API 호출 구조                         │
├─────────────────────────────────────────────────────────────┤
│  1. System Message (OpenAI만)     ~200 토큰                 │
│  2. User Prompt                                              │
│     ├─ Few-shot 예시             ~300 토큰                  │
│     ├─ 고객 컨텍스트             ~150 토큰                  │
│     ├─ 브랜드 톤                 ~30 토큰                   │
│     ├─ 발신목적 지침             ~80 토큰                   │
│     └─ 출력 형식 지시            ~30 토큰                   │
├─────────────────────────────────────────────────────────────┤
│  총 Input Token 예상: ~800 토큰                              │
│  Output Token 예상: ~200 토큰                                │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 고객 컨텍스트 (context_builder.py)

**위치**: [context_builder.py:33-73](../context_builder.py#L33-L73)

**구성 요소**:

#### A. 기본 프로필 (항상 포함)
```
고객 프로필:
- 이름: 민지
- 나이/직업: 25세, 직장인, SNS 활발, 트렌디한 제품 선호
- 피부: 복합성 / 모공, 피지
- 관심: 트렌디 메이크업, 가성비 좋은 제품
- 패턴: 월 2-3회 온라인 구매
```

#### B. 발신목적별 추가 컨텍스트 (파생 지표)

**위치**: [context_builder.py:75-142](../context_builder.py#L75-L142)

| 발신 목적 | 추가 컨텍스트 | 계산 함수 |
|----------|--------------|----------|
| `promotion` | 할인 의존도, 프로모션 반응 | `calculate_discount_dependency()`, `calculate_promotion_response()` |
| `new_product` | 고객 유형, 트렌드 민감도 | `classify_customer_type()` |
| `best_curation` | 고객 가치(CLV), 주 브랜드 | `calculate_customer_value()` |
| `repurchase` | 재구매 타이밍, 구매 모멘텀 | `calculate_repurchase_timing()`, `calculate_purchase_momentum()` |
| `churn_prevention` | 휴면 상태, 이탈 확률, 위험 요인 | `get_dormancy_status()`, `calculate_churn_probability()` |
| `seasonal_gift` | 선물 구매 여부, 고객 가치 | `calculate_customer_value()` |

**예시 (promotion)**:
```
할인 혜택 강조:
- 할인 의존도: 높음 (80%)
- 프로모션 반응: 적극적
- 권장: 쿠폰/적립금 강조
-> 혜택 내용 명확히, 압박 금지
```

#### C. 고객 유형별 톤 지시

**위치**: [context_builder.py:144-192](../context_builder.py#L144-L192)

```
고객 유형 맞춤 지시:
- 성향: 🎯 실용 효율형 (기능성 중심, 효과)
- 쇼핑: 🧠 뷰티 인텔리 (비중 40%)
- 상태: 활성 (이탈 15%)

💬 톤앤매너 지시:
제품 효능과 가격 대비 가치 강조
성분/효능 정보 상세히, 전문적 톤
```

**고객 유형 분류** (6가지):

| 유형 코드 | 유형명 | LLM 지시 |
|----------|-------|---------|
| trend | 트렌드 탐색형 | 신제품/트렌드 키워드 활용 |
| practical | 실용 효율형 | 효능과 가격 대비 가치 강조 |
| value | 가치 지향형 | 성분/철학 깊이있게 |
| sensitive | 민감 케어형 | 순함/저자극 강조 |
| premium | 프리미엄 추구형 | 프리미엄 서비스 언급 |
| budget | 합리 소비형 | 가성비 강조 |

**쇼핑 페르소나** (8가지):

| 코드 | 유형명 | 추가 지시 |
|------|-------|----------|
| smart_saver | 똑똑한 절약러 | 할인 혜택 명확히, 가격 대비 가치 강조 |
| beauty_intel | 뷰티 인텔리 | 성분/효능 정보 상세히, 전문적 톤 |
| pro_care | 프로 케어러 | 프리미엄 서비스 언급, 전문 관리 강조 |
| home_routine | 홈 루틴러 | 편안한 톤, 일상 루틴 친화적 |
| genderless | 젠더리스 뷰티 | 중성적 표현, 트렌디한 톤 |
| petit | 쁘띠 뷰티 | 부담없는 톤, 트렌드 언급 |
